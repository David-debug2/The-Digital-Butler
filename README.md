# My Portfolio

A Discord-inspired portfolio website showcasing UI/UX design and frontend development work.

## Features

- Interactive Discord-like interface
- Responsive design
- Customizable themes
- Project showcases and case studies
- Commission pricing and process information

## Setup

1. Clone or download the repository
2. Open `index.html` in a web browser
3. For local development, run `npm start` to start a local server

## Deployment

This site is optimized for GitHub Pages. Ensure script paths are relative (not absolute) for proper loading.

## Technologies Used

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (ES6+)
- Lucide Icons

## Optimization Notes

- Scripts are loaded with relative paths for GitHub Pages compatibility
- Semantic HTML for better SEO and accessibility
- ARIA labels for screen readers
- Minified external resources where possible

## Customization

Edit the data in `_sdk/data_sdk.js` to update content.
Modify styles in the `<style>` tag or create separate CSS files.
